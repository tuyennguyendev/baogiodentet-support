# Bao giờ đến Tết — Trang hỗ trợ

Website tĩnh song ngữ cho ứng dụng Bao giờ đến Tết. Không cần cài dependency hoặc chạy bước build.

- `index.html`: hướng dẫn và câu hỏi thường gặp bằng tiếng Việt.
- `index-en.html`: nội dung tương ứng bằng tiếng Anh.
- `support.css`: giao diện dùng chung của hai trang hỗ trợ.
- `index.js`: sao chép email, ghi nhớ ngôn ngữ và năm ở chân trang.
- `privacy.html`, `terms.html`: chính sách và điều khoản song ngữ.

Xem cục bộ bằng `python3 -m http.server 8000`, sau đó mở `http://localhost:8000`.
